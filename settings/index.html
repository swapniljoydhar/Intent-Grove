User-study participation

Off by default

Checking study availability…

Participation is optional and separate from normal extension settings. The current study disclosure is shown below.

What the extension stores if you opt in: a random study code, your consent state, local study start and expiry times (using this device’s clock), and weekly counts of sessions started; choice cards shown, dismissed, or acted on; and reflection notes shown, reviewed, or dismissed. The local start time is used only to calculate relative study weeks and is not exported. After the configured retention period passes on this device’s clock, the local record is deleted the next time the extension checks study data; no background alarm is used.

What it does not store for this study: browsing URLs, titles, domains, search terms, page contents, intention text, notes, exact path sequences, diagnoses, or survey answers. A reviewed export contains only the study ID, random study code, relative week numbers, and those counts. The extension does not upload it; a separate survey provider is governed by the disclosure above.

Local-storage limitation: the extension uses Chrome local extension storage and does not add app-layer encryption. The disclosed protection relies on this device’s operating-system and browser-profile access controls. Downloading creates a separate file that this extension cannot recall. Withdrawal deletes this extension’s local copy; use the disclosed study contact for exported files or separately collected survey data.
